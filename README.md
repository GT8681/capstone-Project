🏟️ Capstone Project: SOCCER SCOUT PRO
Questo progetto è una piattaforma per la gestione di giocatori di calcio, con sistema di Login e Preferiti.

🚀 Funzionalità
Login/Registrazione: Accesso sicuro per gli utenti.
Dashboard Player: Visualizzazione dei campioni con filtri,in piu' altr funzionalita' come aggiungere e cancellare il Player.
Sistema Preferiti: Salva i tuoi giocatori cliccando sul cuore.
Responsive: Funziona perfettamente su PC e Cellulare.
🛠️ Tecnologie Usate
Frontend: React.js, Vite, Bootstrap.
Backend: Node.js, Express, MongoDB.
Hosting: Vercel (Frontend) & Render (Backend).
📦 Installazione
Clona la repo: git clone [link-tua-repo]
Installa le dipendenze: npm install
Crea un file .env con la tua MONGODB_URI.
Avvia il progetto: npm run dev.
